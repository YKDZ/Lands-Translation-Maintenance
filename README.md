# Lands 简体中文翻译维护

本仓库是 [正式翻译发布仓库](https://github.com/YKDZ/Lands-Simplified-Chinese-Translation) 的维护仓库，以 [lioni](https://github.com/YKDZ/lioni) 框架为基础设施构建原生翻译 QA 管线以提升翻译可用性和质量。

QA 管线检查的范围包括：

- 翻译是否全部完成
- 翻译中的 HTML 标记、MiniMessage 标记、Lands 原生标记等是否与原文相同且正确配对
- 翻译是否采用了规定的术语
- 翻译的一致性
- 翻译是否满足 [个人风格](https://github.com/YKDZ/Lands-Simplified-Chinese-Translation#%E7%BF%BB%E8%AF%91%E9%A3%8E%E6%A0%BC)
- 翻译文件的 YAML 结构是否合法
- 角色名等 Lands 本身有结构要求的字段是否合法
- 是否有无法与原文对应上的 YAML 键
- 是否正确使用了间隔
